\begin{abstract}
Agreement between kinase selectivity scores can change with the analysis
protocol. Across four profiling datasets, we show how affinity weighting,
floor-coded pairs and compound eligibility alter agreement between scores.
We evaluate recovery from random smaller panels jointly with compound
coverage: high rank agreement among the compounds still scorable can conceal
the loss of narrowly active compounds. Moving an activity boundary also
changes rankings, so its value must be fixed by protocol. Separately, we
propose four criteria for selectivity scores and characterize gated entropies
within a stated class of affinity-weighted scores using Shannon's grouping
rule. We prove the scale range that guarantees monotonicity when a weakly
bound target is added. These guarantees do not confer an empirical recovery
advantage over simpler scores. Selectivity comparisons should report score
implementation, activity eligibility, boundary sensitivity and retained
compound coverage.
\end{abstract}

\noindent\textbf{Keywords:} binding selectivity,
chemoinformatics, drug discovery, kinase inhibition, ranking stability.
