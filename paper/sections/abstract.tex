\begin{abstract}
Across four kinase profiling datasets, affinity weighting, floor-coded pairs
and compound eligibility alter agreement between selectivity scores. On
random smaller panels, rank agreement with the full panel can remain high
even as compounds with few active targets become unscorable. Moving the
activity cutoff changes rankings, so it should be fixed by protocol. We also
link four proposed design criteria to score formulas and parameters. Within
the class studied, the criteria allow only exponential affinity weights. 
We derive the scale range that
prevents added weak binding from increasing apparent selectivity. On these
datasets, the resulting gated entropy has no recovery advantage over simpler
scores. Comparisons should report how scores are calculated, which compounds
can be scored, sensitivity to the activity cutoff, and how many compounds
remain scorable.
\end{abstract}

\noindent\textbf{Keywords:} binding selectivity,
chemoinformatics, drug discovery, kinase inhibition, ranking stability.
