Which file to upload in each slot
========================================================

MAIN DOCUMENT (Word, with tracked changes)
  Your Google-Docs tracked-changes file (the full manuscript text with redline
  markup vs. the reviewed version).
  - This is the marked-up Main Document.
  - Keep the figure and table CAPTIONS in it. Figures and tables themselves are
    uploaded separately (see below); at revision Molecular Informatics wants
    them as separate files, so you may either leave them embedded for the
    reviewer's convenience or replace each with a "[Figure N here]" /
    "[Table N here]" callout. Leaving them embedded is the safer default.

  molecular_informatics_submission.docx

  cover_letter.txt

FIGURES  (one file per figure, separate slot each)  -> submission_figures/

  Figure3.png  = recovery from random subpanels: coverage, pair recovery and

TABLES  (one file per table, separate slot each)  -> submission_tables/

GRAPHICAL ABSTRACT / TOC
  Image:  figures/toc_graphic.png   (5.0 x 5.6 cm at 600 dpi; rebuild with toc_graphic.py)

SUPPORTING INFORMATION
  supporting_information.pdf (compiles with: latexmk -pdf supporting_information.tex)
  Sections S1-S8 with Tables S1-S9 and Figures S1-S4: dataset construction
  and target selection; score implementations and agreement; ranking
  sensitivity and profile associations; the criteria D2 to D4 and the
  gated entropy (proofs, characterization, variants); recovery from subpanels, including the
  analysis without the D1 gate; cross-dataset and supplementary comparisons;
  the clinical analysis; and the script behind every result. Referenced from
  the main text as "Supporting Information, Section S<n>", "Table S<n>" or
  "Figure S<n>".
